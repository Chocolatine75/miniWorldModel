**Date:** 2026-05-25  
**Hackathon:** HackTheWorld(s) — May 2026 (Yann LeCun)  
**Team:** 4 people, 1 day, Kaggle T4 GPU  
**Approach:** A — Layered build: CartPole first, MiniGrid via config flag  

---

## 1. Goal

Build a minimal action-conditioned world model (mini AC-JEPA) on Gymnasium environments, then plan with it using CEM and MPPI optimizers. The output is a GitHub repo + demo GIF suitable for embedding in a hackathon PDF application.

The project must be:
- Technically credible (all losses from eb_jepa: VICReg + IDM, both CEM and MPPI)
- Readable by beginners (type hints, docstrings with tensor shapes, no magic numbers)
- Runnable end-to-end on Kaggle T4 in one notebook command

## 3. Environment Layer (`src/env.py`)

**Purpose:** Unified Gymnasium wrapper that handles seeding, observation normalization, and discrete action encoding for both CartPole and MiniGrid.

**Key function:**
```python
def make_env(env_id: str, seed: int) -> gym.Env: ...
def set_seed(seed: int, env: gym.Env) -> None: ...  # torch + numpy + random + env
```

**CartPole-v1:** obs shape `(4,)`, 2 discrete actions.  
**MiniGrid-Empty-8x8-v0:** obs is a dict with `image` key, shape `(H, W, 3)` uint8 → normalized to `(3, H, W)` float32.

## 4. Data Pipeline (`src/data.py`)

**Purpose:** Collect random rollouts and expose them as a PyTorch Dataset.

**collect_random_rollouts(env, n_episodes) → saves `data/rollouts.pt`**  
Each rollout is a list of `(obs, action, next_obs)` tuples.  
The `.pt` file contains a list of dicts: `{"obs": Tensor, "action": Tensor, "next_obs": Tensor}`.

**RolloutDataset(path):** PyTorch Dataset returning `(obs, action, next_obs)` tensors.  
Train/val split: 90/10 by episode index.

## 5. Model (`src/model.py`)

**Interface contract (never changes between CartPole and MiniGrid):**
- `Encoder(obs: Tensor[B, *obs_shape]) → z: Tensor[B, emb_dim]`
- `Predictor(z: Tensor[B, emb_dim], a_onehot: Tensor[B, n_actions]) → z_next: Tensor[B, emb_dim]`

### MLPEncoder (CartPole)
```
obs (B, 4) → Linear(4, 128) → ReLU → Linear(128, 128) → ReLU → Linear(128, emb_dim) → z (B, emb_dim)
```

### CNNEncoder (MiniGrid)
```
obs (B, 3, H, W) → Conv2d(3,32,3) → ReLU → Conv2d(32,64,3) → ReLU → AdaptiveAvgPool → Flatten → Linear(64*k, emb_dim)
```

### GRUPredictor
```
[z (B, emb_dim) ; a_onehot (B, n_actions)] → Linear → GRU(hidden=128) → Linear → z_next (B, emb_dim)
```

### IDMHead (Inverse Dynamics)
```
[z_t ; z_{t+1}] → Linear(2*emb_dim, 128) → ReLU → Linear(128, n_actions) → logits
```
Used only during training to compute `idm_loss`. Not used at planning time.

### WorldModel wrapper
Holds `encoder`, `predictor`, `idm_head`. Provides `forward(obs, action, next_obs)` that returns all intermediate tensors needed by losses.

### Factory
```python
def build_encoder(cfg) -> nn.Module:
    if "CartPole" in cfg.env_id:
        return MLPEncoder(cfg.obs_dim, cfg.emb_dim)
    else:
        return CNNEncoder(cfg.emb_dim)
```

## 6. Losses (`src/losses.py`)

All losses operate on batches of embeddings `z: Tensor[B, emb_dim]`.

| Loss | Formula | Purpose |
|---|---|---|
| `pred_loss(z_hat, z_next)` | `MSE(z_hat, stop_grad(z_next))` | JEPA prediction |
| `var_loss(z)` | `mean(max(0, 1 - std(z, dim=0)))` | Prevent variance collapse |
| `cov_loss(z)` | `sum(off_diag(cov(z))²) / emb_dim` | Decorrelate embedding dims |
| `idm_loss(logits, a)` | `CrossEntropy(logits, a)` | Encoder must encode action info |

**Total:** `L = pred + α·var + β·cov + γ·idm`  
**Defaults in config:** `alpha=1.0, beta=1.0, gamma=1.0`

**Collapse detection:** after each epoch, if `mean(std(z, dim=0)) < 0.01` → print a red warning.

## 7. Training Loop (`src/train.py`)

```
for epoch in range(n_epochs):
    for batch in train_loader:
        z_t   = encoder(obs)
        z_t1  = encoder(next_obs)          # stop_grad applied in pred_loss
        z_hat = predictor(z_t, a_onehot)
        idm_logits = idm_head(z_t, z_t1)

        loss = pred_loss + α*var_loss(z_t) + β*cov_loss(z_t) + γ*idm_loss
        loss.backward(); optimizer.step(); optimizer.zero_grad()

    save checkpoint
    print: "Epoch {e}/{n} | loss={:.4f} | pred={:.4f} | var={:.4f} | cov={:.4f} | idm={:.4f} | lr={}"
    check collapse

generate loss_curves.png
```

**Config params:** `lr=1e-3, batch_size=256, n_epochs=20, checkpoint_every=1`

## 8. Planner (`src/plan.py`)

**Interface:** `plan(model, obs, goal_obs, cfg) → action: int`

### CEM loop (default)
1. Encode `z0 = enc(obs)`, `z_goal = enc(goal_obs)` — no grad
2. Sample `N=512` action sequences of length `H=15` uniformly from `{0, ..., n_actions-1}`
3. For each sequence, roll predictor: `ẑ_1, ..., ẑ_H`
4. Score = `sum_t ||ẑ_t - z_goal||²`
5. Top-K=64 elites → resample from their empirical distribution
6. Iterate 5 times → return first action of best sequence

### MPPI (method="mppi")
Same as CEM but step 5 uses softmax-weighted mean of elites (temperature `λ=10`). ~10 lines of change.

**MPC wrapper:** `run_mpc_episode(model, env, goal_obs, cfg)` — executes plan → step → replan loop, records frames.

## 12. Technical Conventions

- Type hints everywhere (the team doesn't know PyTorch — type hints are documentation)
- Docstrings on every function with tensor shapes: `"""obs: (B, obs_dim) → z: (B, emb_dim)"""`
- `assert` tensor shapes at start of non-trivial functions
- `device = "cuda" if torch.cuda.is_available() else "cpu"` at top of each entry-point, passed explicitly
- `set_seed(seed)` helper handles `torch`, `numpy`, `random`, `env.reset(seed=seed)`
- No frameworks (Lightning, Hydra, Accelerate) — plain PyTorch + argparse
