# README + Three.js Visualization — Design Spec

Date: 2026-05-26

## Goal

Make the README visually compelling for a hackathon jury (HackTheWorld(s)) while staying unpretentious. The jury should understand in under 10 seconds that the pole is actively balancing — not because it was programmed to, but because a learned world model imagines the future.

Secondary audience: ML/GitHub visitors who want to dig into AC-JEPA after seeing the result.

## Tone

Sober, direct. No marketing badges, no emoji overkill. Numbers speak for themselves in the results table. The video does the selling.

---

## Deliverables

### 1. `viz/index.html` — Three.js CartPole renderer

Standalone HTML file. Loads `viz/trajectory.json` and replays the CEM episode with:
- Dark background (`#0a0a0f`)
- Metallic cart on a track
- Glowing pole tip with a motion trail (last 15 positions)
- Smooth 60fps animation
- Camera slightly follows the cart horizontally
- Loops automatically

No server needed — served via `python -m http.server --directory viz`.

### 2. `viz/trajectory.json` — pre-recorded trajectory

Generated by `python -m src.plan --export-viz`. Schema:

```json
{
  "frames": [
    { "cart_x": 0.02, "pole_angle": 0.01, "action": 1 },
    ...
  ]
}
```

Versioned in the repo so the viz works without running the model.

### 3. `src/plan.py` — `--export-viz` flag

New CLI flag added to the existing `__main__` block. Runs `run_mpc_episode`, collects `(cart_x, pole_angle, action)` per step, writes to `viz/trajectory.json`. No changes to existing `--demo` path.

### 4. `checkpoints/model_ep020.pt` — checkpoint in repo

Model is ~420KB (emb_dim=32, hidden_dim=128). Fine for git.
Remove `*.pt` from `.gitignore`. The final checkpoint is the only `.pt` file versioned.

### 5. `assets/demo.mp4` — screen capture of the Three.js viz

~10 seconds, 60fps, captured from `viz/index.html` running in browser. Replaces `demo.gif` as the README hero asset. `comparison.gif` is removed from the README (redundant once the mp4 exists) but the file stays in `assets/` — no deletion.
